# Программа и методика испытаний

## Условия

- современный браузер Firefox, Chrome или Edge;
- JavaScript включён;
- для автоматических тестов установлен Node.js 20 или новее.

## Автоматическая проверка

Команда:

```bash
npm test
```

Ожидаемый результат: все тесты завершены со статусом `pass`, ошибок нет.

## Ручные сценарии

1. Открыть приложение и создать задачу со всеми полями.
2. Попытаться сохранить пустую форму и увидеть сообщения об ошибках.
3. Изменить название и приоритет созданной задачи.
4. Отметить задачу выполненной и проверить счётчики.
5. Найти задачу по предмету.
6. По очереди применить фильтры состояния и приоритета.
7. Обновить страницу и убедиться, что данные сохранились.
8. Экспортировать данные, затем импортировать файл.
9. Удалить задачу: сначала отменить, затем подтвердить.
10. Повторить основные действия при ширине окна 390 px.
