# Архитектура приложения

StudyFlow выполнен как одностраничное веб-приложение без серверной части.

## Слои

1. **Клиентский слой** — браузер пользователя.
2. **Презентационный слой** — HTML и CSS, которые формируют интерфейс.
3. **Бизнес-слой** — JavaScript-функции для проверки, сортировки, фильтрации и подсчёта задач.
4. **Ресурсный слой** — хранилище `localStorage` и JSON-файл резервной копии.

## Поток данных

Пользователь вводит данные в форму. Контроллер проверяет поля и передаёт готовую задачу в хранилище. После изменения состояния приложение заново получает список, применяет фильтры и обновляет интерфейс.

Такое разделение позволяет отдельно тестировать правила работы с задачами и при необходимости заменить локальное хранилище на серверное API.
