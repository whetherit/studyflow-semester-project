# Техническое задание

## 1. Общие сведения

Наименование: веб-приложение «Учебный планировщик StudyFlow».

Исполнитель: Агафонов Глеб Артемович, группа АСУб-25-2.

## 2. Назначение и цель

Система предназначена для личного учёта учебных заданий. Цель создания — уменьшить риск пропуска сроков и сделать текущую нагрузку наглядной.

## 3. Характеристика объекта автоматизации

Объектом является процесс планирования самостоятельной работы студента по нескольким дисциплинам.

## 4. Требования к системе

Система должна поддерживать создание, изменение, удаление, выполнение, поиск и фильтрацию задач, показывать статистику и сохранять данные локально. Полный список приведён в `requirements.md`.

## 5. Состав работ

Анализ проблемы, проектирование интерфейса и архитектуры, программирование, тестирование, подготовка документации и презентации.

## 6. Контроль и приёмка

Приёмка выполняется по таблице из `acceptance-criteria.md` и результату автоматических тестов.

## 7. Подготовка к вводу

Пользователю нужен современный браузер с поддержкой JavaScript и localStorage.

## 8. Документирование

В репозиторий входят README, техническое задание, описание архитектуры, руководство пользователя, план испытаний и протокол проверки.

## 9. Источники

- ГОСТ 34.601-90 «Автоматизированные системы. Стадии создания»;
- учебные материалы по ИТ-архитектуре и жизненному циклу ПО;
- документация MDN по HTML, CSS, JavaScript и Web Storage API.
