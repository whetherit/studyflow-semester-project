# Жизненный цикл проекта

Разработка построена по этапам, приведённым в ГОСТ 34.601-90 и в материалах дисциплины.

1. **Формирование требований** — изучена проблема хранения учебных заданий.
2. **Разработка концепции** — выбрано локальное веб-приложение.
3. **Техническое задание** — определены функции и критерии приёмки.
4. **Эскизный проект** — составлена структура экрана и слоёв приложения.
5. **Технический проект** — выбраны HTML, CSS, JavaScript и localStorage.
6. **Рабочая документация** — подготовлены исходный код, руководство и тесты.
7. **Ввод в действие** — приложение проверяется в браузере и публикуется в репозитории.
8. **Сопровождение** — ошибки можно фиксировать через GitHub Issues и устранять отдельными коммитами.
