# Критерии приёмки

| № | Критерий | Как проверить |
|---|---|---|
| 1 | Новая задача появляется в списке | Заполнить форму и нажать «Сохранить» |
| 2 | Пустое название не принимается | Отправить форму без названия |
| 3 | Изменения сохраняются | Изменить название существующей задачи |
| 4 | Удаление требует подтверждения | Нажать кнопку удаления |
| 5 | Выполнение меняет состояние задачи | Установить флажок на карточке |
| 6 | Поиск находит название и предмет | Ввести часть текста в строку поиска |
| 7 | Фильтры скрывают неподходящие задачи | Выбрать состояние или приоритет |
| 8 | Счётчики совпадают со списком | Сравнить статистику с карточками |
| 9 | Данные переживают перезагрузку | Добавить задачу и обновить страницу |
| 10 | Резервная копия восстанавливается | Экспортировать, очистить и импортировать данные |
| 11 | Интерфейс работает на ширине 360 px | Проверить адаптивный режим браузера |
| 12 | Автоматические тесты проходят | Выполнить `npm test` |
