# Требования к StudyFlow

## Функциональные требования

1. Пользователь может добавить учебную задачу.
2. У задачи есть название, предмет, срок и приоритет.
3. Пользователь может изменить созданную задачу.
4. Пользователь может удалить задачу после подтверждения.
5. Задачу можно отметить выполненной и вернуть в работу.
6. Задачи можно искать по названию и предмету.
7. Список можно фильтровать по состоянию и приоритету.
8. На экране отображается общая статистика.
9. Данные сохраняются после перезагрузки страницы.
10. Пользователь может экспортировать и импортировать резервную копию.

## Нефункциональные требования

- приложение работает без отдельного сервера;
- интерфейс понятен без обучения;
- основные действия доступны с клавиатуры;
- приложение удобно на экране телефона и компьютера;
- открытие интерфейса и фильтрация выполняются без заметной задержки;
- данные не отправляются в интернет.
