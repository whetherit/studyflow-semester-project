# Руководство пользователя

## Запуск

Откройте `index.html` двойным щелчком или выполните `npm start` и перейдите по адресу `http://localhost:8080`.

## Работа с задачами

1. Нажмите «Новая задача».
2. Заполните название, предмет, срок и приоритет.
3. При необходимости добавьте комментарий.
4. Нажмите «Сохранить».

Флажок слева отмечает задачу выполненной. Кнопка с карандашом открывает редактирование, кнопка с крестиком удаляет задачу после подтверждения.

## Поиск и фильтры

Строка поиска проверяет название и предмет. Два списка рядом позволяют показать задачи нужного состояния или приоритета.

## Резервная копия

Кнопка «Экспорт» сохраняет задачи в JSON-файл. Чтобы восстановить данные, нажмите «Импорт» и выберите ранее сохранённый файл.

## Демонстрация

Кнопка «Пример» загружает три готовые задачи. Если в приложении уже есть данные, оно спросит подтверждение перед заменой.
