# StudyFlow

StudyFlow — простой учебный планировщик для студентов. Приложение помогает записывать задания, следить за сроками и отмечать выполненную работу.

Проект создан для семестровой работы по дисциплине «Введение в профессиональную деятельность».

![Интерфейс StudyFlow](docs/images/studyflow-desktop.png)

## Возможности

- создание, изменение, удаление и выполнение задач;
- поиск по названию и предмету;
- фильтры состояния и приоритета;
- статистика и выделение просроченных задач;
- локальное сохранение без регистрации;
- экспорт и импорт JSON-файла;
- адаптивный интерфейс.

## Запуск

Откройте файл `index.html` в браузере или запустите локальный сервер:

```bash
npm start
```

После этого откройте `http://localhost:8080`.

## Проверка

```bash
npm test
```

Документы проекта находятся в каталоге `docs`.
