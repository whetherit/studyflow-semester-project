# StudyFlow

StudyFlow — простой учебный планировщик для студентов. Приложение помогает записывать задания, следить за сроками и отмечать выполненную работу.

Проект создан для семестровой работы по дисциплине «Введение в профессиональную деятельность».

## Запуск

Откройте файл `index.html` в браузере.
